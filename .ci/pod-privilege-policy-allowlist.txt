# <check> is privileged | hostPath | runAsUser | automount | secret |
# serviceAccount, or * for all of them.

# Pod-level securityContext), the Secret name for `secret`, the
# ServiceAccount name for `serviceAccount`, or * for any subject.

# "go and check this Pod still needs it", removing one means the privilege
# is gone.

# automountServiceAccountToken: false; there is no entry for that check in
# this file today because no Pod here needs the projected token.
